# React Node Auth App

This is a full-stack authentication app built with:

- Frontend: React
- Backend: Node.js
- Database: PostgreSQL
- ORM: Prisma

## Features
- User signup/login
- JWT authentication
- Protected routes

## Setup
1. Clone the repository
2. Run `npm install` in both client and server folders
3. Run `npm start` to start the app
